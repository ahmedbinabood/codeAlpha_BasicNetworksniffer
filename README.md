Basic Network Sniffer Using Python

Project Description

This project is a basic network sniffer developed using Python and Scapy. It captures IP packets and displays source IP, destination IP, protocol, packet size, and packet summary.

Technologies Used

- Python
- Scapy
- Npcap

Features

- Captures 20 IP packets
- Displays source and destination IP addresses
- Identifies TCP, UDP, and ICMP protocols
- Displays packet size and summary

How to Run

1. Install Python.
2. Install Scapy using "pip install scapy".
3. Install Npcap on Windows.
4. Open Command Prompt in the project folder.
5. Run "python network_sniffer.py".

Note: Only capture traffic on networks you own or have permission to monitor.
